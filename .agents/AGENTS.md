# Reglas para el Agente Antigravity

- **Idioma de Comunicación**: A partir de ahora, toda comunicación con el usuario debe ser en español.
- **Idioma del Código y Comentarios**: El código nuevo, las funciones, las variables, los comentarios y la documentación dentro del código deben escribirse en español (o inglés según el estándar del proyecto, pero priorizando la solicitud del usuario para explicaciones y comentarios en español).
- **Consejos y Retroalimentación**: Todos los consejos, explicaciones, sugerencias y respuestas a preguntas deben ser formulados en español de manera clara, concisa y profesional.
- **Formato**: Usar enlaces a archivos y símbolos según la guía de estilo (`[filename](file:///path/to/file)`).
